# StudyOS

**StudyOS is a lightweight all-in-one student workspace that brings document editing, spreadsheets, presentations, calendars, habit tracking, and other productivity tools into one desktop-style environment.**

Built with **HTML, CSS, and JavaScript**, StudyOS is designed to provide a practical productivity experience while staying lightweight enough to run smoothly on **low-end PCs**.

## 🚀 Core Tools

### 📄 Document Editor

A Google Docs-inspired document editor for creating and editing documents directly inside StudyOS.

* Create and edit documents
* Format text and organize content
* Work in a familiar document-style interface
* Designed for schoolwork, assignments, notes, and written projects

### 📊 Spreadsheet Editor

A spreadsheet tool inspired by applications such as Microsoft Excel and Google Sheets.

* Create and edit spreadsheets
* Organize information into rows and columns
* Work with structured data
* Useful for school projects, calculations, planning, and data organization

### 🖥️ Presentation Editor

A PowerPoint-inspired presentation editor for creating and organizing slide-based presentations.

* Create presentations
* Add and organize slides
* Build school projects and presentations
* Work from a familiar slide-based interface

### 📅 Calendar

A built-in calendar designed to help students manage their schedules and stay organized.

* View and organize your schedule
* Keep track of important dates
* Plan study sessions and activities
* Manage deadlines and events

### 🔄 Habit Tracker

A habit-tracking tool designed to help build and maintain consistent routines.

* Create personal habits
* Track daily progress
* Monitor consistency over time
* Build better study and productivity routines

### 📝 Notes & Organization

Quick tools for capturing ideas, information, reminders, and school-related content without needing to leave the workspace.

### ⏱️ Productivity Tools

StudyOS brings useful productivity features together so students can manage their work, planning, and routines from one place.

## 🖥️ One Workspace

Instead of switching between multiple applications and browser tabs, StudyOS brings its tools together inside a **single desktop-style workspace**.

Open the tools you need, switch between them, and keep your productivity environment organized in one place.

## ⚡ Lightweight by Design

StudyOS is built using:

* **HTML5**
* **CSS3**
* **JavaScript**

The project focuses on keeping the interface lightweight and responsive, making StudyOS suitable for **low-end and older PCs** while still providing a modern productivity experience.

## 🎓 Built for Students

StudyOS is designed around the everyday needs of students — from writing assignments and creating presentations to organizing schedules, tracking habits, and managing schoolwork.

The goal is to provide a **single, accessible workspace for studying, organization, and productivity**.
